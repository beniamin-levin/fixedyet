Reproduce before you answer

Paste a public GitHub issue. An agent on NVIDIA Nemotron writes a pytest reproduction, runs it in a Docker sandbox at the reported version and again on main, and fixed rules, not the model, decide the verdict.

A live run takes 1.5 to 5 minutes. See a finished one first: an open bug in Jinja, reproduced, then a one-line fix verified against its 911 tests.

Try one: (open bug)· (open bug)· (fixed on main)

Works on pure-Python projects tested with pytest. An issue from a repository GitHub lists as another language, a pull request, or a number with no issue behind it is turned away before a run is counted.

    Each side runs the test twice. Confidence is high only when every run agrees, neither side errored, and no low-confidence row applies. Issue text is treated as data, and all code runs in a sandbox.
